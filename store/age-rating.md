# Age rating answers

The answers for the IARC questionnaire (Google Play), the App Store age rating, and the Microsoft Store. They describe what is **built into** the app. People can import their own models, sprites and sounds, which the stores treat as user-generated content that isn't shared through the app.

**Expected rating:** IARC 7+ / PEGI 7, ESRB Everyone 10+, App Store 9+. These are driven by mild cartoon fighting.

| Topic | Answer | Why |
|---|---|---|
| Violence | Mild, cartoon / fantasy | Characters can "fight" and attack with a knockback push; there is no blood, injury, death or weapons shown being used on people |
| Fear / horror | Infrequent, mild | Characters can flee from monsters; night and storm moods |
| Sexual content or nudity | None | |
| Language | None | Built-in names and lines contain no profanity. Lines are typed by the user |
| Controlled substances | None | |
| Gambling (real or simulated) | None | |
| User interaction / chat | No | No online features, chat or sharing between users inside the app |
| Shares location | No | |
| Digital purchases | No (0.19). Paid tiers later would be a licence file, still with no data collected | |
| Unrestricted web access | No | The app never connects to the internet |
| User-generated content | Made and kept on the device only | Imports aren't shared with anyone through the app; the share sheet is the system's |
| Data collected | None | See privacy-policy.md |

## Store content notices

- **Uploads:** "Files you import are your responsibility. Use only models, sprites and sounds you have the right to use." Shown in the import panels (Phase J, 0.20).
- **Names:** style names stay generic (Blocky, Anime fantasy, Pixel 2D, Low-poly), with no game brand names in the listing or the app.
